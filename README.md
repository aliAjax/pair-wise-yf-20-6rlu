# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 全场停火恢复台

在原编排台基础上补齐停火 / 恢复工作流（单页内完成，无新页面、新依赖、新服务）：

- 每个点火节点三态：**已点火**（实际点火时刻记录，只读）、**待点火**、**停火挂起**。
- 节目时钟走时（开始/暂停/+5s/+15s/时间跳转），到时的待点火节点自动结算为已点火。
- 「触发全场停火」：立即冻结时钟，所有未完成节点挂起；已点火记录保持只读；停火期间挂起/待点火节点都不能直接点火，也不能新增节点。
- 时间轴（含停火时刻虚线、播放头）、点位平面图（A/B/C 三点，状态色）、型号清单（型号汇总 + 完整节点表）与冲突提示（同点位间隔 <1.2 秒）共享同一状态。
- 恢复批复：勾选挂起节点整组批复，必须填写**安全复核人**，新点火时间**不得早于停火时刻**；与同点位已点火记录间隔不足 **1.2 秒**、或本批复组内同点位相互不足 1.2 秒时**整组拒绝，原挂起状态与表单不变**。
- 至少一批恢复成功后允许「结束停火」；挂起节点全部恢复时自动结束停火。
- 全部状态（节点、停火时刻、审计留痕、时钟位置）写入 `localStorage`，刷新页面后保留；走时中刷新会按离线时长补走并结算到时节点。「重置演练」可恢复初始编排。
