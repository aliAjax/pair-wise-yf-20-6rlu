# hxyfront-62008 烟花燃放脚本编排

源提示词编号：10

我想做一个面向烟花燃放编排师的燃放脚本前端工具，可以记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点。页面需要有时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 技术栈

React + Vite + TypeScript

## 全场停火恢复台

- 每个点火节点实时标记：已点火 / 待点火 / 停火挂起。
- 触发全场停火：未完成节点全部挂起，已点火记录只读，挂起节点不能直接点火。
- 恢复燃放：须填写安全复核人和不早于停火时刻的新点火时间；挂起组以最早计划时间为锚点整体平移。
- 安全校验：任一挂起节点的新点火时间与同点位已点火记录间隔不足 1.2 秒，整组拒绝且原状态不变。
- 时间轴、点位图、型号清单同源渲染，全部状态经 localStorage 持久化，刷新保留；无新增页面、依赖或服务。
